# Lista de Tarefas

Aplicação web simples para organizar tarefas do dia a dia, feita com HTML, CSS e JavaScript puro (sem bibliotecas).

## Funcionalidades

- Adicionar tarefas
- Marcar como concluída
- Apagar tarefas
- Filtrar por todas, pendentes ou concluídas
- Limpar todas as concluídas de uma vez
- Contador de tarefas pendentes
- As tarefas ficam salvas no navegador (localStorage), então continuam lá ao recarregar a página

## Como usar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Tecnologias

HTML5, CSS3 e JavaScript (ES6+).
